## Regression analysis: Government debt and GDP growth in Finland[regression-analysis-finland-gov-debt.pdf.pdf](https://github.com/user-attachments/files/25092159/regression-analysis-finland-gov-debt.pdf.pdf)

Empirical macroeconomic analysis using Finnish time-series data (1976–2024).

- Method: OLS regression
- Dependent variable: Real GDP growth
- Key explanatory variable: Government debt-to-GDP ratio
- Additional variables: COVID-19 dummy and interaction term
- Diagnostics: Breusch–Pagan test, VIF

The analysis finds no statistically significant relationship between public debt and GDP growth,
highlighting the importance of country-specific factors and model limitations.

This project was completed as part of my university coursework.
